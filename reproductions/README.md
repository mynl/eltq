# Reproductions with eltq

Published results rebuilt with `eltq` and `aggregate`. Each page has the shape of a chapter of the aggregate Reproductions book (context and problem, the paper's solution and gold standard, the reproduction, comments), so it can move into that book whole.

| Page | Paper |
|---|---|
| `Homer2017a.qmd` | Homer and Li (2017), *Notes on using property catastrophe model results*, CAS E-Forum, with its presentation |

## Building

Prerequisites: Quarto 1.10 or later, tectonic, uv, PowerShell 7, and the Rust toolchain that builds `eltq`.

```powershell
.\render.ps1                    # every page
.\render.ps1 Homer2017a.qmd     # one page
```

`render.ps1` runs `uv sync`, which builds this directory's environment in `.venv` with `eltq` from the checkout one level up and everything else from PyPI, then renders to PDF through the house style in `_extensions\house`. After a change to `eltq`, `uv sync --reinstall-package eltq` picks it up.

`references.bib` is generated by `make_bib.py` from the shared bibliography and is not edited by hand: `uv run python make_bib.py <path to the library .bib>`.
